# 主动词库

把「认识但不会用」的英文词，练成会在作文里主动用出来的词。

背单词和写作用词是断开的：阅读时认得的词，落到笔上就是想不起来，想起来了搭配也常常错。主动词库不加新的背诵环节，而是把你已经在背的词直接塞进一段限定写作任务里——勾词、按这批词出题、读 AI 示范或自己写、AI 逐词判定用没用出来、搭配地不地道，用出来且地道才算真正掌握。

## 使用教程

顶部三个视图：**写作**（`#/write`）、**词本**（`#/words`）、**习作集**（`#/saved`）。

1. **收词**。到「词本」，点「粘贴收词」，把你正在背的笔记整段粘进去——不规定格式，一串单词、一段带释义的笔记都能进；也可以「手动填一个」。词库不预设任何词，首屏是空的，空着时给一段样例，点「试试粘这段」就能走一遍完整流程。整理的结果是词卡：词头、词性、释义与搭配，例句在点开词卡的学习视图里补。
2. **选词出题**。到「写作」，左栏「本次目标词」点 2~5 个词，题干按这批词的共同主题生成：勾海洋主题的词，出的就是海洋的题。再选篇幅档位——**自动**（句数 = 目标词数，2~8 句）/ **短** 2~3 句 / **中** 4~6 句 / **长** 7~10 句。
3. **练用**，两条路共用同一篇幅要求：
   - **A 读 AI 示范短文**：按题干和档位现写一段，先整段连着读（带全文译文），再切「逐句讲解」看译文、句子结构和按成分切分的高亮原句；点任意单词看它在这句里的释义，词库里没有的词可以直接收进词库。
   - **B 我自己写**：写完提交，AI 逐词判定有没有用出来、搭配自然不自然，给得分和可以直接抄的改法。写作时实时显示句数/词数偏短、达标还是偏长。
4. **攒习作**。两条路的结果都能「保存这篇」，存进「习作集」那一屏（最多 50 篇），每行给来源、自动取的名字、篇幅、目标词和是否已带讲解；没讲过的示范可以在习作集里点「补分析」补上。存的东西只在这台设备，换浏览器看不到，也不上传。
5. **看进度**。每个词有掌握度：`认识` →（读完示范）`练用中` →（自己写出来且搭配地道）`会用`。只升不降，读示范最多到 `练用中`，亲手写对才算 `会用`。词卡列表按掌握度筛选。

**关于额度**：不带密钥的访客用站点密钥生成，一台设备 5 次免费示范，用完页脚会提示。在页脚粘上自己的 DeepSeek 密钥（`sk-…`）之后就花你自己的额度；输入框是密码型、保存即清空，界面只显示尾号，密钥只留在本机浏览器和请求头里。任何一路 AI 调用没走成，界面都会写明原因并回落到本地兜底结果，不假装成功。

## 技术栈

- **前端**：Vite 7 + TypeScript 5.6，**不用框架**。视图是模板字符串 + `escapeHtml` 转义，状态放在模块闭包里，改动走整屏重绘；没有虚拟 DOM 和运行时依赖，构建产物就是静态资源。
- **样式**：`src/style.css` 一套设计令牌，美术方向「羊皮纸 × 铁胆墨」——米纸底、墨字、赭红细线，层级靠纸面明度阶梯而不是灰度涂色；英文词头 Bodoni、正文 Newsreader、数字 DM Mono，字体子集全部本地化在 `public/assets/fonts/`。
- **AI 网关**：Deno Function（`functions/`，单文件、按路径尾段路由），前端只调同源 `/functions/v1/app/{intake, model-text, explain, gloss, feedback}` 五个路由；站点密钥不下发浏览器，生成类请求在前端排队，一次只跑一路。
- **模型**：DeepSeek 的 OpenAI 兼容接口。环境变量 `API_KEY`（站点 Secret，兜底）、`AI_MODEL`（默认 `deepseek-chat`）、`AI_BASE_URL`（换服务商时用）；密钥只在 edge 运行时读取，打包产物里没有。
- **存储**：浏览器 localStorage，无账号、无服务端数据库——词库 `tianchi.words`、任务 `tianchi.tasks`、习作集 `tianchi.saved`、自带密钥 `tianchi.modelkey`。每个浏览器只看得见自己的数据。
- **部署**：Qoder Sites（项目 slug `active-vocab`），`dist/` 静态产物 + `functions/` 同源网关。

## 目录

```
src/
  main.ts             # 顶栏与三屏 hash 路由、页脚密钥、跨屏回调接线
  types.ts            # Word / WritingTask / Feedback / PassageLength 契约
  features/words/     # 词本：收词、词卡列表与筛选、学习视图、localStorage
  features/writing/   # 写作：选词出题、示范与讲解、逐词判定、保存这篇与习作集、AI 客户端与降级
functions/            # Sites Function：五个路由的网关实现
public/assets/        # 本地字体、卡片与动效样式、分享图
dev/                  # 网关断言与本地假上游
docs/                 # 任务清单与过程截图
```

## 本地开发

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 产出 dist/
npm run typecheck  # 类型检查
```

不调真实模型也能跑完整闭环：`node dev/function-stub.mjs` 起本地假上游（监听 127.0.0.1:8000，vite 会把 `/functions/v1/app` 代理过去），`node dev/handler-node-test.mjs`、`node dev/passage-test.mjs` 是网关与分句的逻辑断言。装了 Deno 时真实入口是 `deno run --allow-net --allow-env functions/index.ts`。

## 协作约定

- `main` 为可信主干：按功能开 `feat/xxx` 分支，合并走 PR，另一人 review；共享文件（`src/types.ts`、`src/main.ts`）的改动一律走 PR。
- **Mock 先行，互不阻塞**：词库与写作各自在自己的 `src/features/*` 目录内开发，跨目录只经 `types.ts` 契约。
- 任务认领看 `docs/issues.md`，一个任务一条 GitHub Issue；关键步骤截图存 `docs/process/NN-MM-DD-描述.png`。
